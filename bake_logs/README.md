# Bake Logs

This directory stores dated records of actual baking sessions.

A bake log should capture:

- what recipe was used,
- what changed from the prior version,
- what happened during mixing, fermentation, shaping, and baking,
- how the final product was judged,
- what should change next time.

Recommended filename style:

- `YYYY-MM-DD-short-name.md`

Each log should reflect what actually happened, not what was intended to happen.
