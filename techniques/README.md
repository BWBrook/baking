# Techniques

This directory stores general process notes that apply across more than one
recipe.

Examples:

- fermentation timing,
- Dutch oven use,
- oven and vessel notes,
- fan-forced oven adjustments,
- scalds and soakers,
- preferments and pre-doughs,
- shaping patterns,
- scoring styles,
- flour handling notes by grain type,
- historical adaptation notes,
- mixed-flour design principles.

Current note files:

- `baseline-practice.md`
- `historical-and-mixed-grain-direction.md`
- `leavening.md`
- `oven-and-vessel-notes.md`
- `preferments.md`
- `retard-and-cold-proofing.md`
- `scalds.md`
