# Historical Breads

Use this folder for bread recipes that aim to reconstruct or adapt older baking
traditions.

This includes:

- ancient and classical breads,
- medieval loaves,
- early modern breads,
- Georgian-period breads,
- modern reconstructions inspired by historical sources.

Recommended practice:

- distinguish clearly between what is historically attested and what is a
  modern adaptation,
- record source texts or references where possible,
- note where ingredient substitutions are being made for practicality,
- track how the result compares with both the historical intent and modern
  eating quality.

- `georgian-style-wholemeal-household-loaf.md`
- `panis-quadratus.md`
