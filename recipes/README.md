# Recipes

This directory stores working recipes and stable house recipes.

Suggested subfolders:

- `breads/` for yeasted and naturally leavened breads, with `modern/` and
  `historical/` as the main internal split,
- `flatbreads/` for unleavened or low-structure doughs,
- `other-bakes/` for cakes, quick breads, biscuits, and similar items,
- `templates/` for reusable drafting formats.

Working file:

- `ingest.md` is the temporary intake file for rough recipe notes, spoken-note
  dumps, and partial ideas that still need to be processed into their proper
  long-term locations.

Recommended practice:

- one file per recipe family,
- revise recipes in place with clear notes,
- link to related bake logs,
- promote a recipe from trial to stable only after repeated success,
- after processing `ingest.md`, move the useful content into the correct recipe,
  research, inventory, or technique files and reset `ingest.md` for reuse.
